This project is for a GoHighLevel (GHL) hosted website built with drag and drop custom code and page level custom code (CSS window, header tracking, footer tracking).
GHL only accepts plain HTML, CSS and JavaScript.
All the containers of the code blocks have their margins and padding set to 0 so the code can dictate the whole UI.
Website should perform all the intended functions (such as hovers, scroll reveals, auto-scroll, pause on hover, etc.) smoothly while optimizing page speed.
GHL is sometimes known to override certain things, so the before producing code it is important for the AI bot to inform itself on what the limitations look like and how they can be overcome in the code.
Header and footer will be shared across the home page, privacy policy and terms of service pages through global containers.
Contents of the pages will be in non shared page specific containers.
Home Page's content (hero, slider, difference, process, faq, contact) is hosted in one container with separate custom code blocks.
This is to reduce risk of making page level changes when editing the hero section for A/B tests.
